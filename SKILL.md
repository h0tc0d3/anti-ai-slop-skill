# Anti-AI-Slop Writing

Preserve meaning, facts, and voice. Leave code, config, logs, commands, payloads,
and quotations intact. User instructions, required formats, and necessary
technical terms override all style rules here and in references.

## Load References

Paths are relative to this skill. Load only when needed; reuse loaded references:

- [Banned lists](references/banned-lists.md): before drafting or reviewing prose.
- [Structures](references/structures.md): for drafts over two sentences.
- [Examples](references/examples.md): if rules are unclear or revisions still
  sound synthetic. Illustrations, not reusable facts.

## Write or Revise

1. Match samples and channel register, including humor, slang, and swearing.
   Default to direct, conversational prose and natural contractions.
2. Replace banned wording or recast sentences. Cut filler and habitual hedging;
   retain real uncertainty.
3. Vary sentence and paragraph lengths. Avoid padded threes, staccato runs,
   formulaic contrasts and endings. Name known actors; retain useful connectors.
   Use fragments only when the voice calls for them; never force roughness.
4. Prefer supported names, numbers, dates, and actions. Never invent facts,
   studies, quotes, or anecdotes. Label hypotheticals; keep unknowns uncertain.
5. Prefer no em dashes; maximum one per 500 words. Maximum one exclamation mark
   per 1,000 words and one ellipsis per piece, for trailing off only. Use colons
   and semicolons naturally.
6. Use headings, lists, and emphasis where useful. Omit decorative bold, emoji
   bullets, and thread banners unless requested. Maximum two relevant hashtags;
   no Markdown in plain-text channels.

## Check Before Returning

Check banned wording (especially adverbs), structure, flow, specifics, and limits.
Score directness, rhythm, trust, authenticity, and density 1–10 each; revise below
35/50. Fix factual errors, changed meaning, and missed requirements at any score.
Return requested text only; explain rules or scores only if asked.
